# Gyrotron Control System

A full-stack control application for Gyrotron systems, featuring React frontend, FastAPI backend, and OPC UA integration with Beckhoff TwinCAT PLC.

## Architecture

- **Frontend**: React + TypeScript (Vite)
- **Backend**: Python FastAPI + Pydantic
- **Communication**: OPC UA (asyncua)
- **Reverse Proxy**: Nginx
- **PLC**: Beckhoff TwinCAT

## Directory Structure

- `/frontend`: Web user interface
- `/backend`: API, Safety Logic, and OPC UA client
- `/nginx`: Web server configuration
- `/plc`: TwinCAT project files/exports
